## 시작하기
### 사전 요구사항
- Java 17
- MySQL 8.4.7
### .env.local 생성 및 로컬 환경 세팅
```
./scripts/setup-local.sh
```
### 빌드
```
./gradlew build
```

## 애플리케이션 실행
```
./gradlew bootRun
```
